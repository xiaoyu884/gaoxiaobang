# 高校邦助手

用于 `*.class.gaoxiaobang.com` 的 Tampermonkey 用户脚本，入口文件为 `gxb-helper.user.js`。它读取当前课程的页面数据，调用站内接口处理视频、阅读和讨论，并通过 DeepSeek 为选择题填写答案。

## 安装与使用

1. 在浏览器中安装支持 `GM_*` API 的用户脚本管理器，例如 Tampermonkey。
2. 在管理器中新建脚本，将 `gxb-helper.user.js` 的完整内容粘贴进去并保存、启用。安装更新时替换同一脚本的内容。
3. 登录高校邦并打开课程章节页。脚本等待课程数据就绪后运行；浏览器开发者工具的控制台会显示进度与失败原因。完成当前阶段后，脚本会尝试打开下一项待完成测验或页面上的下一任务。
4. 如需 AI 答题，在用户脚本管理器的脚本菜单中选择「⚙️ 设置 DeepSeek API Key」，填入自己的 Key；通过「⚙️ 设置 DeepSeek 模型」设置模型，默认值为 `deepseek-chat`。菜单中留空保存 API Key 可清除它。

默认模式仅填写答案，提交前由使用者检查并点击提交。「🤖 切换答题模式」可切换为自动提交；只有本轮所有题目都成功解析并填入时，脚本才会尝试点击提交按钮。

失败或等待数据超时后，可使用「▶️ 运行 / 重试当前页面」或刷新页面重试。「🔁 重置当前课程脚本状态」清除当前账号、站点、课程的阶段及已处理记录，刷新后生效；API Key、模型、答题模式和其他课程的记录保留。任务运行期间不能重置。

## 实际行为

- **视频与阅读：** 获取视频时长后向视频日志接口上报，读取阅读章节接口，并等待这些请求结束。成功的章节会记录；有失败则保留进度阶段，不进入讨论阶段或下一任务，使用菜单或刷新后重试尚未成功的章节。
- **讨论：** 获取每个专题的现有回复。如果已发现当前用户的回复则跳过；否则复制返回列表中最长的可用评论，间隔约 5 秒提交，并重新获取回复列表检查当前用户是否出现。没有可复制评论的专题仍待处理，可手动处理后重试；失败的专题也留待重试。只有没有待处理专题时才进入下一任务，课程没有专题时可完成讨论阶段。
- **测验：** 等待全部题目的选项 DOM 就绪，最多约 15 秒；超时不调用 AI。支持 `multiple_answers` 题型和 `gxb-icon-check` 多选图标。提取题干、选项和选项 ID 后，将题干与选项发送给 DeepSeek，解析其返回的选项字母并选择对应答案。响应格式错误、请求失败、题目或选项缺失、填写失败等情况会阻止本轮自动提交。即使课程进度已标记完成，打开测验页仍会触发答题。
- **下一任务：** 优先按照课程数据或目录顺序寻找待完成测验，使用页面已有的实际链接；页面使用 `chapterId` 哈希路由时，沿用该路由切换章节并保留其他参数。也支持已有的 `/unit/{unitId}/chapter/{chapterId}` 路由，使用目录中的单元归属切换章节。最早一项待完成测验没有可用路由时停止，展开目录后可通过菜单重试。全部已知测验完成后不再使用下一任务按钮重开它们；有书面作业时转至作业入口，没有可识别的测验或作业目录时才尝试页面上的下一任务控件。链接须属于同一站点、课程。
- **书面作业：** 进度与讨论处理完成、已知测验均已处理后，打开目录中实际存在且已解锁的 `Assignment` 入口，随后停留供使用者自行写作与提交。会等待作业目录链接加载，约 15 秒后仍未就绪则停止，可通过菜单重试；脚本不代写或提交书面作业。
- **页面内切换：** 支持课程页面内部的下一任务切换。哈希路由切换后，等待新题目数据与选项 DOM 对应就绪，再重新答题；旧任务的请求结果不会应用于新任务。课程 ID 以 URL 为准，检测到同一页面内切换至另一课程后刷新，读取新课程数据再运行。
- **提交后推进：** 手动提交和自动提交均需页面出现明确的当前测验完成或提交结果，才记录已处理测验并尝试推进；仅点击提交、看到分数标签或通用成功提示不会触发推进。如果进度或讨论阶段仍待处理，会先继续这些阶段；出现失败时停止自动导航。
- **独立测验结果页：** 对 `/quiz/{quizId}/submission/{submissionId}` 页面，优先核对 `quizSubmission` 中的 `quizSubmissionId`，兼容 `submission`/`submissionId`，并核对测验 ID，单独记录已提交的测验 ID，再返回保存的同课程来源页继续目录。没有可靠返回地址时停留并提示使用页面「返回」。课程 ID、上下文 ID 不会作为章节 ID 使用。目录中的服务器历史记录入口也可用于识别本地记录建立前已提交的测验。
- **状态：** 运行阶段、已处理章节、专题和测验按站点、账号、课程隔离，旧版未隔离的状态不会作为当前课程的运行依据。阶段 `completed` 只表示进度与讨论处理完成，不表示测验或书面作业均已完成。API Key、模型和答题模式也存放在用户脚本管理器的脚本存储中。

## 数据与限制

调用 DeepSeek 时，题干、选项及 API Key 会发送至 `api.deepseek.com`；站内请求使用当前浏览器的登录会话。模型回答可能错误，严格格式解析只能确认返回格式，不能确认答案正确。

脚本依赖高校邦页面的全局数据、DOM 和站内接口，这些结构变化后可能需要修改代码。请求成功、脚本状态完成或讨论列表中出现回复，均不能证明平台最终认定课程进度或测验成绩有效。复制讨论内容和提交测验会实际影响当前账号，使用者应核对内容并自行负责提交决定。

当前版本为 1.3.7。本地回归验证使用模拟页面和模拟网络请求，覆盖题目数据先于选项 DOM 就绪等情况。真实 Firefox 课程中已观察到结果页返回课程、跳过历史已提交测验、进入下一测验并填写全部两题。后续多个测验循环中，也观察到多选题填写、页面显示提交成功，以及提交后返回课程继续推进。另一课程中已确认两次视频上报请求成功，通过回复列表核对了两次讨论发帖，并自动打开尚未提交的书面作业页，停留供使用者完成。这些验证不保证答案正确、平台最终认定进度有效或所有高校邦站点均兼容。

## 本地验证

需要 npm，以及符合 jsdom 引擎要求的 Node.js：20.19 及以上的 20.x、22.13 及以上的 22.x，或 24 及以上版本。在项目根目录执行：

```sh
node --check gxb-helper.user.js
cd gxb-tests
npm ci # 首次运行或依赖需恢复时执行；已有依赖可跳过
npm test
```

测试依赖保存在 `gxb-tests/package.json` 和锁文件中；测试不会访问真实课程或 DeepSeek 服务。
