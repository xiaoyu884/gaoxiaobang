# 我不想上高校邦

**I Don't Wanna Take Gaoxiaobang** — 仓库：[i-dont-wanna-take-gaoxiaobang](https://github.com/xiaoyu884/i-dont-wanna-take-gaoxiaobang)。

用于 `*.class.gaoxiaobang.com` 的 Tampermonkey 用户脚本，入口文件为 `gxb-helper.user.js`。它读取当前课程的页面数据，调用站内接口处理视频、阅读和讨论，并通过 DeepSeek 为选择题填写答案。

后续开发与发布安排见 [兼容性与发布蓝图](docs/release-blueprint.md)，包含按优先级排序的工作流、依赖与验收标准。

## 安装与使用

1. 在浏览器中安装支持 `GM_*` API 的用户脚本管理器，例如 Tampermonkey。
2. 首次安装时，在管理器中新建脚本，将 `gxb-helper.user.js` 的完整内容粘贴进去并保存、启用。已有安装请打开原脚本的编辑器，替换完整内容并保存。
3. 登录高校邦并打开课程章节页。脚本默认暂停，「视频 / 阅读进度」「发布讨论回复」「AI 测验答案」三个模块默认关闭。在页面控制面板中勾选需要的模块，再点击「开始 / 重试」；点击「暂停」停止本轮执行。浏览器开发者工具的控制台会显示进度与失败原因。
4. 如需 AI 答题，在用户脚本管理器的脚本菜单中选择「⚙️ 设置 DeepSeek API Key」，填入自己的 Key；通过「⚙️ 设置 DeepSeek 模型」设置模型，默认值为 `deepseek-chat`。菜单中留空保存 API Key 可清除它。配置 Key 不会自动启动脚本。

修改模块勾选会暂停执行，需再次点击「开始 / 重试」。模块偏好由用户脚本管理器存储并在标签页间共享，运行授权则属于当前标签页，并绑定开始时的模块选择。另一个标签页修改模块也会使当前授权失效，脚本在下一操作检查或轮询中暂停并尽力中止请求，受影响标签页需重新开始。关闭模块不会将它尚未处理的任务标记完成；重新开始后，其他已启用模块仍可继续。AI 答题关闭时，脚本不会进入测验、调用模型、填写答案或自动提交；使用者仍可手动完成当前测验，在脚本已开始且确认提交结果后继续任务导航。

当前标签页的运行授权通过 `sessionStorage` 保留，同一账号、课程的刷新和任务导航可继续；新课程或账号切换需要重新开始。暂停会尽力中止待处理请求并阻止后续操作，无法撤回服务器已经接受的请求。已有 API Key、模型、提交模式及课程状态保留。

默认模式仅填写答案，提交前由使用者检查并点击提交。「🤖 切换答题模式」可切换为自动提交；切换会先暂停再刷新，需明确重新开始。只有本轮所有题目都成功解析并填入时，脚本才会尝试点击提交按钮。

「▶️ 运行 / 重试当前页面」菜单也是明确开始指令，按当前勾选的模块运行。失败或等待数据超时后，可使用该菜单重试；已开始的同课程页面也可刷新重试。「🔁 重置当前课程脚本状态」清除当前账号、站点、课程的阶段及已处理记录，刷新后生效；API Key、模型、答题模式、模块勾选和其他课程的记录保留。任务运行期间不能重置。

## 实际行为

以下自动操作仅在已开始执行且相应模块启用时进行。

- **视频与阅读：** 获取视频时长后向视频日志接口上报，读取阅读章节接口，并等待这些请求结束。成功的章节会记录；有失败则保留进度阶段，不进入讨论阶段或下一任务，使用菜单或刷新后重试尚未成功的章节。
- **讨论：** 获取每个专题的现有回复。如果已发现当前用户的回复则跳过；否则复制返回列表中最长的可用评论，间隔约 5 秒提交，并重新获取回复列表检查当前用户是否出现。没有可复制评论的专题仍待处理，可手动处理后重试；失败的专题也留待重试。只有没有待处理专题时才进入下一任务，课程没有专题时可完成讨论阶段。
- **测验：** 等待全部题目的选项 DOM 就绪，最多约 15 秒；超时不调用 AI。支持 `multiple_answers` 题型和 `gxb-icon-check` 多选图标。提取题干、选项和选项 ID 后，将题干与选项发送给 DeepSeek，解析其返回的选项字母并选择对应答案。响应格式错误、请求失败、题目或选项缺失、填写失败等情况会阻止本轮自动提交。课程进度已标记完成也不影响已启用的 AI 答题模块处理测验。
- **下一任务：** AI 答题启用时，优先按照课程数据或目录顺序寻找待完成测验，使用页面已有的实际链接；页面使用 `chapterId` 哈希路由时，沿用该路由切换章节并保留其他参数。也支持已有的 `/unit/{unitId}/chapter/{chapterId}` 路由，使用目录中的单元归属切换章节。最早一项待完成测验没有可用路由时停止，展开目录后可通过菜单重试。全部已知测验完成后不再使用下一任务按钮重开它们；有书面作业时转至作业入口，没有可识别的测验或作业目录时才尝试页面上的下一任务控件。链接须属于同一站点、课程。
- **书面作业：** 当前已启用模块的阶段处理结束后，打开目录中实际存在且已解锁的 `Assignment` 入口，随后停留供使用者自行写作与提交。会等待作业目录链接加载，约 15 秒后仍未就绪则停止，可通过菜单重试；脚本不代写或提交书面作业。
- **页面内切换：** 支持课程页面内部的下一任务切换。哈希路由切换后，等待新题目数据与选项 DOM 对应就绪，再处理新任务；旧任务的请求结果不会应用于新任务。课程 ID 以 URL 为准，切换至另一课程后需等待新课程目录并重新开始；运行中的课程切换会先暂停并刷新，以读取新课程数据。
- **提交后推进：** 手动提交和自动提交均需页面出现明确的当前测验完成或提交结果，才记录已处理测验并尝试推进；仅点击提交、看到分数标签或通用成功提示不会触发推进。如果已启用的进度或讨论阶段仍待处理，会先继续这些阶段；出现失败或暂停时停止自动导航。
- **独立测验结果页：** 对 `/quiz/{quizId}/submission/{submissionId}` 页面，优先核对 `quizSubmission` 中的 `quizSubmissionId`，兼容 `submission`/`submissionId`，并核对测验 ID，单独记录已提交的测验 ID，再返回保存的同课程来源页继续目录。没有可靠返回地址时停留并提示使用页面「返回」。课程 ID、上下文 ID 不会作为章节 ID 使用。目录中的服务器历史记录入口也可用于识别本地记录建立前已提交的测验。
- **状态：** 运行阶段、已处理章节、专题和测验按站点、账号、课程隔离，旧版未隔离的状态不会作为当前课程的运行依据。阶段 `completed` 只表示进度与讨论处理完成，不表示测验或书面作业均已完成。API Key、模型和答题模式也存放在用户脚本管理器的脚本存储中。

## 数据与限制

调用 DeepSeek 时，题干、选项及 API Key 会发送至 `api.deepseek.com`；站内请求使用当前浏览器的登录会话。模型回答可能错误，严格格式解析只能确认返回格式，不能确认答案正确。

脚本依赖高校邦页面的全局数据、DOM 和站内接口，这些结构变化后可能需要修改代码。请求成功、脚本状态完成或讨论列表中出现回复，均不能证明平台最终认定课程进度或测验成绩有效。复制讨论内容和提交测验会实际影响当前账号，使用者应核对内容并自行负责提交决定。

1.4.0 增加了运行控制面板和模块开关。本地回归验证使用模拟页面和模拟网络请求。在真实 Firefox 与 Tampermonkey 5.5.0 中，已确认更新同一脚本后默认暂停、三个模块关闭；未选模块时拒绝开始；已完成课程可明确开始，同标签页刷新保留授权；修改模块及切换课程会暂停。在 Firefox 的隔离本地页面中，用模拟请求确认了暂停调用请求的中止方法、忽略迟到的答案，以及在模拟提交后暂停会阻止后续确认。隔离页面不访问课程或 DeepSeek 服务；这些测试没有新增真实讨论回复或测验提交，尚未用 1.4.0 完整处理一门未完成课程。

此前 1.3.7 在真实 Firefox 课程中已观察到结果页返回课程、跳过历史已提交测验、进入下一测验并填写全部两题；后续多个测验循环中，也观察到多选题填写、页面显示提交成功，以及提交后返回课程继续推进。另一课程中已确认两次视频上报请求成功，通过回复列表核对了两次讨论发帖，并自动打开尚未提交的书面作业页，停留供使用者完成。这些历史记录与 1.4.0 的执行控制测试范围不同，均不保证答案正确、平台最终认定进度有效或所有高校邦站点均兼容。

## 本地验证

需要 npm，以及符合 jsdom 引擎要求的 Node.js：20.19 及以上的 20.x、22.13 及以上的 22.x，或 24 及以上版本。在项目根目录执行：

```sh
node --check gxb-helper.user.js
cd gxb-tests
npm ci # 首次运行或依赖需恢复时执行；已有依赖可跳过
npm test
```

测试依赖保存在 `gxb-tests/package.json` 和锁文件中；测试不会访问真实课程或 DeepSeek 服务。
